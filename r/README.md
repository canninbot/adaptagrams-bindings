# adaptagrams

This R package exposes native Adaptagrams connector routing and constraint-based
layout for igraph graphs. From the monorepo root, install with:

```r
remotes::install_local("r")
```

The package includes its pinned native sources under `vendor`, so built source
archives do not depend on the monorepo parent directory. See the top-level
README and the igraph vignette for examples and limitations.
