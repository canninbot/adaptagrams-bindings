# Dependency license notes

- Adaptagrams: LGPL-2.1-or-later; exact text is in
  `ADAPTAGRAMS-LGPL-2.1-or-later.txt` and upstream notices remain in source.
- pybind11: BSD-3-Clause, used to build the Python extension.
- scikit-build-core: MIT, build-time only.
- python-igraph: GPL-2.0-or-later, runtime dependency and public object API.
- Rcpp: GPL-2.0-or-later, R linking/build dependency.
- R igraph: GPL-2.0-or-later, runtime dependency and public object API.

Review the dependency versions and their complete license files when preparing
binary distributions. This summary is not legal advice.
